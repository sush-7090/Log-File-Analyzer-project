# Log File Analyzer

## Project Overview
**Log File Analyzer** is a Python-based tool designed to generate, parse, and analyze log files. It detects patterns and anomalies, providing insights into system performance, errors, and security events. The tool includes visualization of log trends and can help administrators and developers monitor and improve application reliability.

## Features
- Generate random log entries for testing purposes.
- Parse logs with timestamps, log levels (INFO, WARNING, ERROR), and messages.
- Detect patterns and count occurrences of log levels.
- Identify anomalies such as spikes in errors or warnings.
- Visualize log trends over time using line charts.
- Optional: Export analysis reports.

## Technologies Used
- **Python** – Core programming language
- **Pandas** – Data manipulation and analysis
- **Matplotlib** – Data visualization
- **Regex** – Pattern matching and log parsing
